# 武汉市洪山区经济分析数据来源调研

调研日期：2026-08-25

## 结论

已确认存在可直接读取的一手来源：武汉市洪山区人民政府门户网站的统计公报、统计分析和月度统计页面。它们发布了洪山区年度、季度和月度经济指标，页面包含发布时间和正文/表格，适合先规范化为本地外部 JSON，再由 Economic Provider 读取。

本阶段不把国家统计局数据查询页面直接作为唯一接口：其网页入口在当前环境返回 403，且区域指标的查询参数与口径需要进一步核验。武汉市统计局页面可作为市级对照和来源目录，但洪山区的首批真实记录优先采用洪山区政府统计信息页面。

## 来源与语义边界

1. 页面发布机构是洪山区人民政府，但正文中的统计数据由统计部门发布；系统应记录发布机构和数据来源页面，不把页面抓取时间误写成统计期间。
2. 公报注明部分数据为“当年快报数”，结果应显示这一限定。
3. 年度、季度、半年和月度期间不能直接混合计算同比趋势；Provider 必须保留 `period_type` 和 `period`。
4. “GDP 运行情况”页面只有 GDP 相关指标，不能据此推断完整经济发展状况；完整问题应触发目录发现或澄清。
5. 来源页面可访问不等于开放许可允许任意再分发。规范化数据仅作为本项目本地演示输入，保留 URL、发布日期、提取日期和来源说明；不提交原始网页快照或大体量数据。
6. 2026 年数据属于截至 2026-08-25 已发布的阶段数据，不应被表述为 2026 全年结果。

## 接入决定

M263 首批真实数据采用“洪山区/武汉市政府统计页面 → 手工/脚本规范化 JSON → Economic Provider”的可审计路径：

- 每条观测保留 `source.url`、`published_at`、`retrieved_at`、`source.field`/正文章节和 `period_type`。
- 原始页面不进 Git；规范化 JSON 放在被 `.gitignore` 忽略的本地 `data/`，通过环境变量传入 Docker。
- 未完整绑定来源、区域层级或期间的记录直接进入 `source_unverified`/`field_mismatch`，不参与 ready 结果。
